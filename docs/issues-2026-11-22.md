# Open issues, reviewed on 22 November 2026

Every open issue of the rulecad repository was read and checked against the code on main (c1fca64), after Frames 4.
Each one is closed as done, kept for a person to print and measure, or kept with the code work left, ranked by what it
gives against what it costs. This page is a record of that review; the issues themselves stay the place to follow
each one.
